# Gestão Rodas - Pontes Rolantes - Vercel Deploy

1. Vai a vercel.com > Add New > Project
2. Faz Import do teu repositório GitHub OU faz drag & drop da pasta (Vercel permite upload)
3. Se não tens GitHub:
   - Instala Vercel CLI: npm i -g vercel
   - Na pasta: vercel --prod
4. Fica com link: https://teu-projeto.vercel.app

Firebase: depois do deploy, entra no link e vai a Config > Cola firebaseConfig
